Place the official Gulf logo here as:  gulf-logo.png
(transparent background, about 240 px wide or larger; it is displayed at 52 px height)

The header and footer load assets/gulf-logo.png automatically.
Until the file exists, a dashed "GULF LOGO" placeholder box is shown.
To use an SVG instead, save it as gulf-logo.svg and change the two
src="assets/gulf-logo.png" references in index.html.

Do not redraw or alter the logo; use the asset supplied by Gulf brand/marketing.
Product pack images: the prototype draws neutral pack placeholders. Real pack
shots can be added per product later (see README.md, section 5).
